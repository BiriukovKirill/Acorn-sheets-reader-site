# Acorn Sheets Reader

Acorn Sheets Reader is a small Python utility for researchers who need to read data from Google Sheets in their analysis scripts.

## What it does

- Authenticates each researcher using their own Google account through Google OAuth 2.0.
- Reads spreadsheet values using the Google Sheets API.
- Respects the permissions of the signed-in Google account.
- Requests read-only access to Google Sheets.

This is a research utility, not a commercial service. It does not provide access to spreadsheets that the signed-in user is not permitted to read.
